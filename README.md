## ✨ What is ADAPT OS?

ADAPT OS is an all-in-one adaptive workspace designed to bring the tools you use throughout your day into one organised environment.

Instead of jumping between separate places to manage tasks, write notes, review finances, organise files, learn or research, ADAPT OS brings these activities together in a single web application.

Its guiding idea is simple:

> **Technology should adapt to the way people work — not force people to work around technology.**

Whether you are a student, creator, developer or someone who simply wants a more organised day, ADAPT OS gives you a flexible place to manage your workflow.

### 🧩 More tools, one environment

ADAPT OS also links to a collection of companion experiences from its navigation:

- **Lumen** — a search, research and coding companion.
- **Google Mode** — a dedicated Google search experience.
- **Student Edition** — a student-focused Adapt OS experience.
- **Studio** — a creative workspace.
- **Snake and Chess** — built-in game experiences.
- **Online Shop** — a commerce experience.
- **Translator** — a translation tool.

These companion pages are included in the repository as separate HTML files.

## 🎨 Designed around your workflow

ADAPT OS is built to feel like a workspace rather than a collection of disconnected pages.

- **Adaptive navigation** keeps the main areas accessible.
- **Responsive layout** supports different screen sizes.
- **Theme controls** let you switch the workspace appearance.
- **Personalisation** lets you configure profile and appearance details.
- **Dashboard overview** brings important workspace information together.
- **Persistent browser storage** keeps supported workspace data available on the device and browser where it was created.

## ⚡ Get started

### Use the live application

Visit **[adapt-personal-app.netlify.app](https://adapt-personal-app.netlify.app)** to open ADAPT OS.

### Run it locally

1. Clone the repository:

   ```bash
   git clone https://github.com/junior-pobee/adapt-os.git
   ```

2. Open the project folder:

   ```bash
   cd adapt-os
   ```

3. Open the folder in your preferred code editor.

4. Start a local development server, for example with the VS Code Live Server extension.

5. Open the local address provided by your development server.

You can also deploy the static project to a compatible static web host. Keep the HTML pages, stylesheets, scripts and referenced assets in their expected relative locations.

## 📁 Project structure

The repository is organised around a browser-based application:

```text
adapt-os/
├── index.html
├── style.css
├── main.js
├── Lumen.html
├── google.html
├── students.html
├── studio.html
├── snake.html
├── chess.html
├── commerce.html
└── translate.html
```

- `index.html` — main ADAPT OS interface.
- `style.css` — application styling and responsive layout.
- `main.js` — workspace behaviour, interactions and browser data handling.
- The additional HTML files provide the companion experiences linked from the main navigation.

## 💾 Your data and browser storage

ADAPT OS uses browser storage for supported workspace information. This means data is associated with the browser and device where it was saved.

- Clearing browser site data may remove locally stored workspace information.
- Data saved in one browser or device does not automatically appear in another.
- Use care when using shared devices.
- Keep separate backups of important information.
